# Docs Scripts

- `node scripts/docs/generate-reference-docs.js backend`
  Generate backend API reference artifacts under `docs/reference/backend-api/`.
- `node scripts/docs/generate-reference-docs.js frontend`
  Generate frontend route and page-to-API reference artifacts under `docs/reference/frontend/`.
- `node scripts/docs/generate-reference-docs.js drift`
  Generate route / Swagger / frontend drift report under `docs/reference/backend-api/`.
- `node scripts/docs/generate-reference-docs.js all`
  Generate all reference artifacts.
